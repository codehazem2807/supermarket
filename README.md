# رفاد — ملاحظات التحديث

## تحديث قاعدة البيانات للإصدار 5.1

بعد تطبيق المخطط الأساسي و`sales_calculation_migration.sql`، طبّق `production_integrity_migration.sql` على مشروع Supabase.

يضيف التحديث:

- استبدال نقاط الولاء داخل معاملة واحدة، مع قفل رصيد العميل والتحقق من الصلاحيات والشركة.
- مفتاحاً ثابتاً لكل عملية بيع غير متصلة، بحيث تعيد المحاولة الفاتورة نفسها بدلاً من إنشاء فاتورة مكررة.

لا تعِد إرسال عمليات البيع القديمة الموجودة في قائمة المزامنة قبل مراجعة سجل المبيعات؛ العمليات التي لا تملك مفتاح UUID ستتطلب مراجعة يدوية لتفادي التكرار.

## إعداد الاتصال

يجب ضبط عنوان المشروع ومفتاح Supabase العام الصحيح في `config.js`. استخدم مفتاح `anon`/publishable فقط في المتصفح، ولا تضع مفتاح `service_role` أو أي سر خاص في ملفات الواجهة.
